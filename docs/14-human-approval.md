# Human Approval Gate & CODEOWNERS Verification

## Mandatory Human Review Requirement

In CodeGuard, **AI review is never a replacement for human peer review.**

### Human vs AI Review Distinction
Every review submission in CodeGuard is tagged with an immutable `reviewType`:
- `HUMAN_REVIEW`: Submitted by a human developer via GitHub/GitLab.
- `AI_REVIEW`: Generated by CodeGuard AI.

The `PolicyEngine.evaluateMergeDecision` gate enforces:
```typescript
const humanApprovals = reviews.filter(
  (r) => r.reviewType === 'HUMAN_REVIEW' && r.state === 'APPROVED'
);
if (humanApprovals.length < branchRule.requiredApprovals) {
  // MERGE BLOCKED
}
```

### CODEOWNERS Engine
CodeGuard parses standard `.github/CODEOWNERS` syntax supporting:
- Root rules (`* @org/core-engineers`)
- Path patterns (`/services/payments/ @payments-team @alice`)
- Extension patterns (`*.sql @dba-team`)

A PR touching files in `/services/payments/` is locked until at least one designated code owner submits a `HUMAN_REVIEW: APPROVED`.
